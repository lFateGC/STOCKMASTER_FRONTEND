# Sprint VI

El documento `Entregable_Integrador_II_Sprint_VI_completado.docx` contiene la versión final del entregable. Las evidencias técnicas, capturas y el ejecutor de pruebas están en [`QA_Sprint6`](../../QA_Sprint6/).

Después del cierre del Sprint VI se aplicaron las solicitudes de simplificación visual del usuario: se retiraron 26 textos explicativos y se compactaron el Dashboard, la navegación y el inventario. El código de esta rama refleja esos ajustes posteriores.

Para comprobar la interfaz: `npm install`, `npm run dev -- --port 4179`, y en otra terminal `npm run test:ui`. Se puede cambiar la URL de pruebas con `QA_BASE_URL`. El ejecutor usa Microsoft Edge y respuestas simuladas para la API; no modifica Supabase.
